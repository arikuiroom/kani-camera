カニギター カメラ Beta

正式版:
https://arikuiroom.github.io/kani-camera/

テスト版:
https://arikuiroom.github.io/kani-camera/beta/

運用方針:
- 新機能はまず beta/ だけ更新します。
- iPhone実機で動作確認して、問題なければ正式版へ昇格します。
- beta の main.js は ../models/ と ../textures/ を参照し、大きな3Dモデル・テクスチャは正式版と共有します。
- beta で不具合が起きても、正式URLの index.html / main.js には影響しません。
- 正式版への反映は、ユーザーが「正式版にして」と明示したときだけ行います。

現在のベース:
Kani Camera v1.16.0 beta


■ v1.11.2 beta 高解像度保存 + 高品質AA
- 保存画像の長辺を約3000pxにしました。
- 画面の縦横比はプレビューと同じまま保存します。
- 3Dカニギターは通常2倍の縦横サイズ（4倍の画素数）でレンダリングし、3000px画像へ縮小して輪郭を滑らかにします。
- 端末のWebGL上限が低い場合は、安全な倍率まで自動で下げます。
- 高品質レンダリングに失敗した場合も、3000pxの通常レンダリングへ自動フォールバックします。
- カメラ入力は対応端末でより高解像度を選べるよう、3840×2160をidealとして要求します。
- 正式版 v1.9.1 は変更していません。


■ v1.11.2 beta 接地影
- カニギターの足元に柔らかい接地影を追加しました。
- 「影」パネルで ON/OFF・濃さ・ぼけ・大きさ・位置を調整できます。
- 影はカニギターの移動・拡大縮小に追従します。
- 保存画像にも影が反映されます。
- v1.10 beta の長辺約3000px高解像度保存は継続しています。
- 正式版 v1.9.1 は変更していません。


■ v1.11.2 beta 影の調整
- 接地影の標準サイズを小さくしました。
- 標準の濃さを弱め、ぼけを強めました。
- カニギターが横向きになるほど、影の横幅も自動で細くなるようにしました。
- 正式版 v1.9.1 は変更していません。


■ v1.11.2 beta 影のデフォルト調整
- 影の大きさのデフォルトを 0.65 に変更しました。
- 影の濃さのデフォルトを 0.50 に変更しました。
- 影のぼけのデフォルトを 0.30 に変更しました。
- 横向き時に影の横幅が細くなる処理は維持しています。
- 正式版 v1.9.1 は変更していません。


■ Beta キャッシュ回避
- Beta版は main.js のURLへ起動ごとに一意のクエリを付け、iPhone Safariが古いJavaScriptを再利用しにくくしました。
- スタート画面に「最新版を再読み込み」ボタンを追加しました。
- このボタンはページURL自体にも一意のクエリを付けて再読み込みします。
- HTMLには no-cache / no-store のヒントも追加しています。
- GitHub Pages側のデプロイ完了待ちは別途必要ですが、デプロイ後のiPhone側キャッシュ遅延を減らすための対策です。
- 正式版には適用していません。


■ v1.12 beta 背景色へのなじませ
- 画面上部に「なじみ」パネルを追加しました。
- 背景色の反映を ON/OFF できます。
- 「なじみ強度」を 0.00〜1.00 で調整できます。初期値は 0.35 です。
- カメラまたは選択写真の平均的な色味を解析し、元のAlbedo色を保ちながら控えめな色かぶりを加えます。
- 夕方の暖色、曇天の青灰色、室内照明などへ自然になじませることを狙った軽量な処理です。
- 照明AUTOがOFFでも「なじみ」がONなら背景色解析は継続します。
- 正式版 v1.11.2 は変更していません。


■ v1.12.1 beta なじみ効果を強調
- 効果確認のため、背景の色かぶりを意図的に強くしました。
- なじみ強度の初期値を 0.75 に変更しました。
- 背景の明るさも強く反映し、暗い写真ではカニギターを大幅に暗くします。
- 強度1.00では極端な比較テストができます。
- 正式版 v1.11.2 は変更していません。


■ v1.12.2 beta カメラ起動後の操作停止修正
- テクスチャ7枚の読み込み完了を待つ top-level await を廃止しました。
- テクスチャをバックグラウンドで読み込みながら、UIのイベント登録を先に最後まで進めます。
- カメラ起動直後に「入力」「照明」「FOV」「色」「影」「なじみ」などが反応しない時間が発生する問題を修正しました。
- v1.12.1 の強い色なじみ・暗部追従は維持しています。
- 正式版 v1.11.2 は変更していません。


■ v1.12.3 beta 描画優先度修正
- カニギターを接地影より必ず後に描画するよう renderOrder を明示しました。
- 接地影は depthTest を無効化し、3D回転時にも影がカニギターの手前へ被らない合成レイヤー扱いにしました。
- カニギター renderOrder=100、接地影 renderOrder=-100 です。
- v1.12.2 のなじみ機能・UI操作修正は維持しています。
- 正式版 v1.11.2 は変更していません。


■ v1.12.4 beta 接地影の前後関係を再修正
- v1.12.3で影のdepthTestを無効にしたため、透明Spriteである影が不透明なカニギターの後から描かれ、逆に最前面へ重なる問題がありました。
- depthTestを有効へ戻しました。
- 接地影をカニギターより十分奥（Z方向 -2.0）へ配置し、カニギター本体に重ならないようにしました。
- 不要になったカニギター側のrenderOrder指定を削除しました。
- 正式版 v1.11.2 は変更していません。


■ v1.13.0 beta 仮想床 + 実形状の投影影
- 「床」パネルを追加しました。
- 床の高さ・傾きを調整でき、床ガイドを表示できます。床ガイドは保存画像には写りません。
- 「床に合わせる」で現在のカニギターの最下点を仮想床の高さへ合わせます。
- DirectionalLight + ShadowMaterial によるリアルタイム投影影を追加しました。
- カニギターは影を落としますが receiveShadow=false のため、セルフシャドウはまだ有効にしていません。
- 投影影の濃さ・ぼけを床パネルから調整できます。
- 従来の楕円接地影は機能を残しつつ初期状態をOFFにしました。
- 正式版 v1.12.4 は変更していません。


■ v1.13.1 beta iPhone傾き自動設定 + 投影影ぼけ修正
- 仮想床に「水平を自動設定」を追加しました。iPhoneのDeviceOrientationから端末ピッチを取得し、床の傾きへ反映します。
- iOSで必要な場合はボタン操作時にモーション/向きセンサーの許可を要求します。
- v1.13.0ではPCFSoftShadowMapに対してradiusを変更していたため、ぼけ調整がほぼ反映されませんでした。
- VSMShadowMapへ変更し、radiusとblurSamplesを「影のぼけ」スライダーへ連動させました。
- 正式版は変更していません。


■ v1.13.2 beta 接地点だけで床を合わせる簡単モード
- 「床」パネルを大幅に簡略化しました。
- 「接地点を置く」を押して、写真/カメラ上の置きたい床位置を1回タップすると、その画面位置から仮想床の高さを決め、カニギターを床へ合わせます。
- 通常は投影影ON/OFFだけを表示し、高さ・傾き・iPhone傾き・濃さ・ぼけ・ガイド等は「細かく調整」の中へ収納しました。
- 接地点マーカーは設定時だけ短時間表示し、保存画像には写りません。
- 床ガイドはデフォルトOFFにしました。
- 正式版 v1.12.4 は変更していません。


■ v1.13.3 beta 接地点モードの投影影消失を修正
- v1.13.2ではタップ位置から床Yを絶対値で作り直していたため、投影影の受け面とカニギター/ライトの関係が崩れ、影が消える場合がありました。
- 簡単モードでは、影が成立している床とモデルの相対関係を維持したまま接地点へ上下移動する方式へ変更しました。
- 簡単モード使用時は投影影を自動ON、床傾きは安定する0°へ戻します。
- DirectionalLightのtargetも接地点付近へ追従させ、シャドウカメラから外れにくくしました。
- 正式版 v1.12.4 は変更していません。


■ v1.14.0 beta 床設定をやめて投影影を直接合わせる方式
- 通常UIから「接地点を置く」を廃止しました。
- 「投影影」パネルの表側は「影の方向」「影の長さ」の2項目だけにしました。
- 仮想床は内部の安定した受け面として固定し、ユーザーは床角度を考えず、写真を見ながら影の見た目を直接合わせます。
- 影の方向はDirectionalLightの方位、影の長さはライトの仰角へ変換します。
- 背景AUTO照明が動いていても、投影影の方向/長さはユーザー指定を優先します。
- 濃さ・ぼけ・床の詳細設定は「細かく調整」に残しています。
- 実形状の投影影、VSMぼけ、セルフシャドウOFFは維持しています。
- 正式版 v1.12.4 は変更していません。


■ v1.15.0 beta 足元追随型の仮想床
- 仮想床の起点をカニギターの現在の最下点（足元）へ自動追随させる方式へ変更しました。
- カニギターを移動すると床・投影影も一緒に追随します。
- 床パネルに「前後回転」「左右回転」「床サイズ」の3スライダーを追加しました。
- 床パネルを開いている間、画面を1本指ドラッグすると床だけを画面方向に上下左右へ微調整できます。
- 薄いグリッドの床ガイドは床パネルを開いている間だけ表示し、保存画像には写りません。
- 影の濃さ・ぼけは「影の調整」へ収納しました。
- v1.14.0の影方向/長さを直接操作する通常UIは外しました。
- 実形状投影影とVSMぼけは維持しています。正式版 v1.12.4 は変更していません。


■ v1.15.1 beta 床高さ調整を追加・UI整理
- 実機テストでカニギターと投影影の間に浮きが見えたため、「床の高さ」スライダーを追加しました。
- 床の高さはカニギターの最下点を基準にした相対オフセットで、カニギターを移動しても追随します。
- 「左右回転」「床サイズ」スライダーを通常UIから削除しました。
- 床の画面ドラッグ移動も外し、カニギター追随 + 高さ調整 + 前後回転という構成に簡略化しました。
- 前後回転、床ガイド、影の濃さ・ぼけは維持しています。
- 正式版 v1.12.4 は変更していません。


■ v1.16.0 beta iPhone省電力ライブプレビュー
- ライブWebGL描画を最大30fpsへ制限しました。120Hz/60Hz端末でも必要以上に描画し続けません。
- カメラ入力のidealを4K(3840×2160)から1080p(1920×1080)へ下げ、30fps上限を指定しました。
- ライブ中の投影影シャドウマップを1024から512へ下げました。
- 保存時だけ投影影を1024へ戻し、保存後は512へ戻します。
- ライブWebGLのdevicePixelRatio上限を2.0から1.5へ下げました。保存時は従来どおり長辺約3000px + 最大2倍スーパーサンプリングで別レンダリングします。
- 疑似環境反射の更新を約4回/秒から約2回/秒、背景AUTO照明/なじみ解析を約400msから約600ms間隔へ緩和しました。
- 保存画像の長辺約3000px、高品質AA、実形状投影影は維持しています。
- 正式版 v1.12.4 は変更していません。
