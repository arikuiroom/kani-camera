カニギター カメラ重ね表示版

これは「本格AR（床面認識）」ではなく、
iPhoneのカメラ映像の上にThree.jsの3Dカニギターを重ねるシンプル版です。

■ 操作
- 「移動」モード：1本指ドラッグでカニギターを移動
- 「3D回転」モード：1本指ドラッグでカニギターを立体的に回転
- 2本指：拡大縮小・画面内回転
- 反転：前面/背面カメラ切り替え
- 撮影：カメラ映像と3Dを合成して画像化
- 隠す：3Dモデルを一時的に非表示
- 位置を戻す：初期位置へ

■ PCで試す
このフォルダでコマンドプロンプトを開き、
    python -m http.server 8000
を実行して
    http://localhost:8000
を開いてください。

■ iPhoneで試す際の重要事項
iPhoneのSafariでカメラを使うには、原則HTTPSで公開されたページが必要です。
PCの localhost はPC自身では動きますが、同じWi-FiのiPhoneから
http://PCのIP:8000 にアクセスしても、カメラAPIはブロックされることがあります。

手軽な実機テスト方法:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel
など、HTTPSで静的サイトを公開できるサービスにこのフォルダ一式を置く。

※ Three.js本体はCDNから読み込みます。オフラインでは動きません。


■ v1.1 iPhone保存改善
- 撮影後の「共有 / 写真に保存」からiOSの共有シートを開きます。
- 共有シートで「画像を保存」を選ぶと写真アプリへ保存できます。
- Web Shareの画像共有に未対応のブラウザでは「ファイルとして保存」が表示されます。


■ v1.2 3D回転操作
- 「移動 / 3D回転」の操作モード切り替えを追加しました。
- 3D回転モードでは、1本指の左右ドラッグで左右方向、上下ドラッグで上下方向にモデルを回せます。
- 2本指でひねる画面内回転の方向を、v1.1とは逆向きに変更しました。
- 「位置を戻す」で大きさも確実に初期状態へ戻るようにしました。


■ v1.3 PBR + カメラ擬似環境反射
- Metallic テクスチャを追加しました。
- Smoothness テクスチャを反転し、Three.js 用 Roughness テクスチャとして使用しています。
- 元FBXのマテリアル色を使わず、MeshStandardMaterialへ置き換えることで赤かぶりを抑えます。
- iPhoneカメラ映像から低解像度の擬似CubeTextureを生成し、金属/艶部分へ弱く環境反射を与えます。
- これは本物の360°環境反射ではなく、Web上で軽く動かすための近似表現です。


■ v1.4 金属反射の黒つぶれ対策
- カメラ映像だけに依存せず、明るいニュートラルな反射を下地として混ぜる方式に変更しました。
- カメラ映像の色や明るさは引き続きリアルタイム反射へ反映されます。
- Metallic の最大強度を少し下げ、極端に黒く沈みにくくしています。
- 反射マップにソフトな白いハイライトを追加し、金属パーツが読みやすくなります。
- ACES tone mapping を追加し、明部の反射が飛びすぎにくいようにしました。

main.js 冒頭付近の以下の値で後から簡単に調整できます:
CAMERA_ENV_BLEND
ENV_REFLECTION_INTENSITY
METALNESS_GAIN
ENV_MIN_BRIGHTNESS


■ v1.5 照明コントロール + バージョン表示
- 画面右上に「照明」ボタンを追加しました。
- AUTOではカメラ映像を低解像度で解析し、平均色・明るさ・明るい方向をThree.jsの照明へゆるく反映します。
- AUTOをOFFにすると、主照明の明るさ・左右方向・上下方向を手動調整できます。
- 色が付きすぎないよう、周囲色は白色光へ控えめに混ぜています。
- 画面右下に「Kani Camera v1.5」を常時表示します。
- 擬似環境反射（v1.4）はそのまま併用します。


■ v1.6 FOV調整
- 画面上部に「FOV」ボタンを追加しました。
- FOVは20°〜80°の範囲で調整できます。
- 初期値は42°です。
- 「42°に戻す」で初期値へ戻せます。
- バージョン表示を Kani Camera v1.6 に更新しました。

■ v1.8 入力切り替え（カメラ / 写真）
- 画面上部に「入力」ボタンを追加しました。
- カメラ入力と、写真アルバムから選んだ画像を背景にする入力を切り替えられます。
- 起動時にも「カメラを開始 / 写真を選ぶ」を選べます。
- 写真モードでも、移動・3D回転・色・照明・FOV・保存をそのまま使えます。
- 合成保存は、カメラモードではカメラ映像 + 3D、写真モードでは選択画像 + 3D を出力します。
- 写真モードでは反転ボタンは無効になります。
- バージョン表示を Kani Camera v1.8 に更新しました。

■ 正式版 / Beta版 運用
正式版:
https://arikuiroom.github.io/kani-camera/

Beta版:
https://arikuiroom.github.io/kani-camera/beta/

- 今後の新機能は、まず beta/ のみ更新します。
- Beta版をiPhone実機で確認し、ユーザーが承認した場合のみ正式版へ反映します。
- beta/main.js はルートの models/ と textures/ を共有するため、大容量アセットを二重保存しません。
- 正式版の index.html / main.js は、承認なしでは変更しません。


■ v1.11.2 正式版
- Beta版で確認した高解像度保存（長辺約3000px）を正式版へ反映しました。
- 3Dを高解像度レンダリングして縮小することで、保存画像の輪郭をなめらかにしました。
- 接地影機能を追加しました。濃さ / ぼけ / 大きさ / 位置を調整できます。
- 影はカニギターの向きに合わせて横幅が変化します。
- 影の初期値は、濃さ0.50 / ぼけ0.30 / 大きさ0.65 / 位置-0.18です。
- main.js はバージョン付きURLで読み込み、正式版更新時に古いJavaScriptキャッシュが残りにくいようにしました。
- Beta版は今後も新機能の先行テスト用として継続します。


■ v1.12.4 正式版
- 承認済みのBeta v1.12.4を正式版へ反映しました。
- 背景の色味と明るさへ強く追従する「なじみ」機能を追加しました。初期強度は0.75です。
- カメラだけでなく、選択した写真への合成でもなじみ機能が動作します。
- 暗い背景ではカニギターも大きく暗くなるよう調整しています。
- テクスチャ読み込みでUI操作が待たされないよう、非同期ロード方式を修正しました。
- 接地影はdepthTestを有効にし、モデルより十分奥へ配置してカニギターへ被らないよう修正しました。
- 正式版のアプリ名を「カニギターカメラ」に統一しました。
- Beta版は引き続き新機能の先行テスト用として残します。
