カニギター カメラ重ね表示版

これは「本格AR（床面認識）」ではなく、
iPhoneのカメラ映像の上にThree.jsの3Dカニギターを重ねるシンプル版です。

■ 操作
- 「移動」モード：1本指ドラッグでカニギターを移動
- 「3D回転」モード：1本指ドラッグでカニギターを立体的に回転
- 2本指：拡大縮小・画面内回転
- 反転：前面/背面カメラ切り替え
- 撮影：カメラ映像と3Dを合成して画像化
- 隠す：3Dモデルを一時的に非表示
- 位置を戻す：初期位置へ

■ PCで試す
このフォルダでコマンドプロンプトを開き、
    python -m http.server 8000
を実行して
    http://localhost:8000
を開いてください。

■ iPhoneで試す際の重要事項
iPhoneのSafariでカメラを使うには、原則HTTPSで公開されたページが必要です。
PCの localhost はPC自身では動きますが、同じWi-FiのiPhoneから
http://PCのIP:8000 にアクセスしても、カメラAPIはブロックされることがあります。

手軽な実機テスト方法:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel
など、HTTPSで静的サイトを公開できるサービスにこのフォルダ一式を置く。

※ Three.js本体はCDNから読み込みます。オフラインでは動きません。


■ v1.1 iPhone保存改善
- 撮影後の「共有 / 写真に保存」からiOSの共有シートを開きます。
- 共有シートで「画像を保存」を選ぶと写真アプリへ保存できます。
- Web Shareの画像共有に未対応のブラウザでは「ファイルとして保存」が表示されます。


■ v1.2 3D回転操作
- 「移動 / 3D回転」の操作モード切り替えを追加しました。
- 3D回転モードでは、1本指の左右ドラッグで左右方向、上下ドラッグで上下方向にモデルを回せます。
- 2本指でひねる画面内回転の方向を、v1.1とは逆向きに変更しました。
- 「位置を戻す」で大きさも確実に初期状態へ戻るようにしました。


■ v1.3 PBR + カメラ擬似環境反射
- Metallic テクスチャを追加しました。
- Smoothness テクスチャを反転し、Three.js 用 Roughness テクスチャとして使用しています。
- 元FBXのマテリアル色を使わず、MeshStandardMaterialへ置き換えることで赤かぶりを抑えます。
- iPhoneカメラ映像から低解像度の擬似CubeTextureを生成し、金属/艶部分へ弱く環境反射を与えます。
- これは本物の360°環境反射ではなく、Web上で軽く動かすための近似表現です。


■ v1.4 金属反射の黒つぶれ対策
- カメラ映像だけに依存せず、明るいニュートラルな反射を下地として混ぜる方式に変更しました。
- カメラ映像の色や明るさは引き続きリアルタイム反射へ反映されます。
- Metallic の最大強度を少し下げ、極端に黒く沈みにくくしています。
- 反射マップにソフトな白いハイライトを追加し、金属パーツが読みやすくなります。
- ACES tone mapping を追加し、明部の反射が飛びすぎにくいようにしました。

main.js 冒頭付近の以下の値で後から簡単に調整できます:
CAMERA_ENV_BLEND
ENV_REFLECTION_INTENSITY
METALNESS_GAIN
ENV_MIN_BRIGHTNESS


■ v1.5 照明コントロール + バージョン表示
- 画面右上に「照明」ボタンを追加しました。
- AUTOではカメラ映像を低解像度で解析し、平均色・明るさ・明るい方向をThree.jsの照明へゆるく反映します。
- AUTOをOFFにすると、主照明の明るさ・左右方向・上下方向を手動調整できます。
- 色が付きすぎないよう、周囲色は白色光へ控えめに混ぜています。
- 画面右下に「Kani Camera v1.5」を常時表示します。
- 擬似環境反射（v1.4）はそのまま併用します。


■ v1.6 FOV調整
- 画面上部に「FOV」ボタンを追加しました。
- FOVは20°〜80°の範囲で調整できます。
- 初期値は42°です。
- 「42°に戻す」で初期値へ戻せます。
- バージョン表示を Kani Camera v1.6 に更新しました。


■ v1.6.1 FOVパネル修正
- 起動時にFOVパネルがむき出しで表示される不具合を修正しました。
- FOVパネルは「FOV」ボタンを押した時だけ表示されます。
- iPhone SafariでFOVスライダーを操作できるよう、タッチ操作設定を明示しました。
- バージョン表示を Kani Camera v1.6.1 に更新しました。


■ v1.7 5色カラーバリエーション
- 画面上部に「色」ボタンを追加しました。
- 赤 / ミント / 黒 / こげ茶 / 赤茶 の5色を切り替えられます。
- 色切り替えはAlbedoテクスチャのみを変更し、Metallic / Roughness / 照明 / 擬似環境反射は共通で使用します。
- 初期色は「赤」です。
- バージョン表示を Kani Camera v1.7 に更新しました。
